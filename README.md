# hero-match

Game match-3 chạy trên trình duyệt (canvas), dự án thử nghiệm để kiểm tra agent swarm.

Stack: TypeScript + Vite + Vitest, Node/npm. Không backend, không DB.

## Cài đặt

```
npm install
```

## Chạy

```
npm run dev
```

## Test

```
npm test
```

## Build

```
npm run build
```

Kết quả nằm trong `dist/`; xem thử bằng `npm run preview`.
